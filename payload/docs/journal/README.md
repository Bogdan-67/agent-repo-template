# Journal

One file per month: `YYYY-MM.md`. Append only. Past months are frozen (the guard blocks edits).

Entry format:

```markdown
## YYYY-MM-DD <topic>

- What was done and why (one to five lines).
- Changed files and artifacts: `path/one.py`, `reports/x.md`.
- Checks/review: tests run, reviewer verdict, or "not reviewed".
- Decisions: ADR-NNNN, or none. STATUS.md: updated / not changed because ...
```

Closed open questions are logged here as `closed: <question>, <how>`.
